# 내 캘린더 — 개인 캘린더 + 육아 홈·시간표

공용 PC(네이버 웨일)에서도 구글 계정 전환·재로그인 없이 개인 일정을 따로 관리하고,
아이들의 **준비물·행사·학원 시간표**까지 한 앱에서 보는 웹 캘린더입니다.
**파일 하나(`index.html`)** 로 동작하고, 일정은 이 브라우저(localStorage) 또는 **비공개 구글 시트**에만 저장됩니다.

**v1.3.2 (2026-11-27)** — 시트를 **연결만 하면 이 기기에만 있던 일정이 저절로 시트로 올라갑니다**
(개인 일정·캘린더·육아 일정·아이 이름). 손으로 「이 브라우저 일정 시트로 올리기」를 누를 필요가 없어
PC와 휴대폰이 어긋나지 않습니다. 시트에서 이미 본 적 있는 ID(다른 기기에서 지운 일정)와 삭제 대기 중인 항목은
올리지 않으므로 지운 일정이 되살아나지 않습니다. 그 버튼은 이제 **시트를 이 브라우저 내용으로 통째로 바꿀 때**만 쓰고,
눌렀을 때 육아 일정과 아이 이름까지 함께 올립니다.

**v1.3.1 (2026-11-26)** — 반복 일정을 구글 캘린더처럼 다룹니다.
**요일 다중 선택**(월·수·금처럼 골라서), **반복 간격**(2주마다·3개월마다…), **반복 기간**(계속 / 종료일 / 횟수)을
개인 캘린더와 육아 일정 양쪽에서 똑같이 쓸 수 있고, 반복 일정을 고치거나 지울 때는
**이 일정만 / 이 일정 및 향후 일정 / 모든 일정** 중에서 고릅니다.
색·완료·반복 규칙·건너뛴 회차는 **`Code.gs`를 다시 배포하지 않아도** `v1.0.x`/`v1.1.0` 백엔드와 동기화됩니다
(메모 끝 `[[pcal:…]]` 태그로 오갑니다).

**v1.3.0** — 상단에 **월 · 주 · 일 · 일정** 보기 탭을 두고, 월간의 날짜 숫자나 주/일 화면의 날짜 머리를
누르면 그 날 **일간 보기**로 바로 이동합니다(숫자 단축키 `1`·`2`·`3`·`4`, `T` 오늘).
일정 하나만의 **색**을 고를 수 있고, 상세의 **[✓ 완료]** 를 누르면 그 일정만 **흑색 체크리스트**로 바뀝니다.

**v1.2.0** — 아래쪽 탭으로 **👶 육아 홈 · 🗓️ 시간표 · 📅 개인 캘린더**를 오갑니다.
육아 일정은 비공개 시트의 `육아일정`·`육아프로필` 탭에 저장되어 휴대폰·PC가 자동으로 맞춥니다.
(기존 `일정`·`캘린더`·`설정` 탭은 그대로입니다 — 예전 일정은 그대로 보입니다.)

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체(HTML+CSS+JS 한 파일). 더블클릭으로 바로 열립니다. |
| `apps-script/Code.gs` | 비공개 구글 시트 백엔드 + 구글 캘린더 전송 API (Google Apps Script) |
| `test/verify.py` | 화면 동작 자동 검증(Playwright, 데스크톱 1440×900 / 휴대폰 390×844) |
| `test/sync.py` | PC·휴대폰 두 기기 동기화 자동 검증(모의 Apps Script 백엔드) |

   이번 주 스트립, 전체/아이 1/아이 2 필터.

   ‹ 이번 주 › 로 주 이동, 종일 일정은 격자 위 줄에.
3. **📅 개인 캘린더** — 기존 그대로(월간·주간·일간·일정, 드래그, 공휴일, 구글 전송).

## 바로 열어 보기

- **PC**: `index.html` 을 웨일에 끌어다 놓거나 더블클릭합니다.
- **휴대폰**: 파일을 열거나, 나중에 GitHub Pages에 올리면 링크로 엽니다.
- **데모 데이터**: 주소 끝에 `?demo=1` 을 붙이면 가상의 일정(운동·가족 외식·투자 복기 등)이 채워집니다.
  (`index.html?demo=1`) 실제 개인정보는 들어 있지 않습니다.
- 앱만으로도 일정 추가·수정·삭제, 캘린더 색 구분, 검색이 모두 이 브라우저에 저장되며 동작합니다.
- 처음 열면 빈 달력에 **「가상 일정으로 둘러보기」** 안내가 떠서, 버튼 한 번으로 데모 일정을 채워 볼 수 있습니다.

## 기기 간 동기화 (v1.1.0)

**PC에서 고친 일정이 휴대폰에도 새로고침 없이 따라옵니다.** Apps Script는 그대로 쓰므로 **다시 배포할 필요가 없습니다.**

### 언제 시트를 다시 읽나 (받아오기)

| 시점 | 동작 |
|---|---|
| 앱을 처음 열 때 | 시트에서 전부 읽습니다 |
| 휴대폰 화면을 다시 켤 때 · 다른 앱에서 돌아올 때 (`visibilitychange`) | 바로 읽습니다 |
| 창을 다시 볼 때 (`focus`) · 뒤로 가기로 돌아올 때 (`pageshow`) | 바로 읽습니다 |
| 인터넷이 다시 붙을 때 (`online`) | 못 올린 변경을 올리고 읽습니다 |
| 앱을 띄워 둔 동안 | 1분마다 한 번씩 조용히 확인합니다(편집 창이 열려 있으면 쉼) |
| 왼쪽 아래 **연결 상태 칩**을 누를 때 | 즉시 읽습니다 (설정의 `↻ 시트에서 새로 고침` 과 같음) |

칩에는 `비공개 시트 연결됨 · 09:43` 처럼 마지막으로 시트를 읽은 시각이 찍힙니다.

### 어떻게 맞추나

- **올리기**: 이 기기에서 만들기·수정·삭제하면 곧바로 시트로 보냅니다. 실패하면(오프라인 등)
  대기열에 남겨 두고 다음 기회에 자동으로 다시 올립니다. 앱을 껐다 켜도 대기열은 남습니다.
- **받기**: 시트가 기준입니다. 시트에서 사라진 일정은 이 기기에서도 사라집니다.
  단 **이 기기가 시트에서 직접 본 적이 있는 일정만** 지웁니다 — 시트에 아직 못 올린
  이 기기 전용 일정은 지우지 않고 **자동으로 시트에 올립니다**(`v1.3.2`부터. 한 번도 시트에 올라간 적 없는 일정만).
  다 올라가고 나면 `설정 → 이 기기에만 있는 일정 올리기` 버튼은 저절로 숨습니다.
- **동시 편집**: 같은 일정을 양쪽에서 고치면 `updatedAt`(수정 시각)이 더 최근인 쪽이 남습니다.
- **빈 시트 보호**: 연결했는데 시트가 비어 있으면 이 브라우저 일정을 지우지 않습니다
  (저장 도중 순간적으로 빈 응답이 오는 경우도 보호).
- **데이터**: 1분 주기 확인은 앱을 보고 있는 동안만 돕니다. 연결을 끊으면 전혀 부르지 않습니다.

### 휴대폰에서 최신 내용이 안 보일 때 (점검 순서)

1. 앱 왼쪽 아래 칩이 **`비공개 시트 연결됨`** 인지 확인합니다. `이 브라우저에만 저장` 이면 그 기기에 시트 주소가 없는 것입니다.
   → 설정에 Apps Script 웹 앱 주소(`.../exec`)를 붙여넣고 **[연결]**, 또는 PC에서 [이 페이지 링크 복사]한 링크로 엽니다.
   (`#s=` 링크로 연 경우 그 주소를 그 기기에 저장하므로, 다음부터는 해시 없이 열어도 계속 연결됩니다. v1.1.0부터)
2. 칩의 시각이 방금 전인지 봅니다. 오래됐으면 칩을 눌러 한 번 새로 고칩니다.
3. 두 기기가 **같은 주소**의 앱을 쓰는지 확인합니다(예: `https://wjoehasa-eng.github.io/personal-calendar/`).
   PC에서 예전에 내려받은 `index.html` 파일을 열고 있으면 그 파일은 새 버전이 아닙니다.
4. 설치형(PWA)으로 열었다면 한 번 완전히 닫았다 다시 엽니다(홈 화면 아이콘을 길게 눌러 종료).

## 비공개 구글 시트 연결 (휴대폰·다른 PC와 같은 일정 보기)

1. 새 스프레드시트를 만들고 이름을 `[비공개] 내 캘린더` 로 정합니다.
2. 메뉴 **확장 프로그램 → Apps Script** → 기본 코드를 지우고 `apps-script/Code.gs` 내용을 그대로 붙여넣고 저장.
3. **배포 → 새 배포 → 유형(⚙) = 웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **모든 사용자** (그래야 페이지에서 부를 수 있습니다)
   - 배포 → 권한 승인 → 웹 앱 URL(`.../exec`) 복사
4. 캘린더 오른쪽 위 **⚙ 설정**에 URL을 붙여넣고 **[연결]**.
   - 처음 한 번 “Google hasn't verified this app” 경고가 나오면 **고급 → (안전하지 않음)으로 이동 → 허용**.
5. 이미 이 브라우저에 일정이 있으면 **연결만 하면 자동으로 시트에 올라갑니다**(`v1.3.2`부터).
   시트 내용을 이 브라우저 일정으로 **통째로 바꾸고 싶을 때만** 설정의 **[이 브라우저 일정 시트로 올리기]** 를 누릅니다
   (육아 일정·아이 이름까지 함께 올라가고, 시트에만 있는 육아 일정은 그대로 둡니다).

시트 탭(`일정`·`캘린더`·`설정`·`육아일정`·`육아프로필`)은 처음 호출할 때 자동으로 만들어집니다.

> **v1.3.0의 일정 색·완료는 다시 배포하지 않아도 두 기기에서 함께 씁니다.**
> 실제 구글 시트의 `일정` 탭에는 `색상`·`완료` 열이 없어도 되고, 앱이 그 값들을 **메모 끝의 작은 태그**
> (`[[pcal:color=#d50000,done=1]]`)로 실어 보내고 읽을 때 조용히 떼어 냅니다. 메모 칸에는 그대로 보입니다.
> `Code.gs`(백엔드 1.2.0)를 새로 배포하면 색·완료는 `색상`·`완료` 열로 따로 저장되고(메모가 더 깔끔해집니다),
> 예전 백엔드 그대로여도 색·완료·반복 규칙·건너뛴 회차가 휴대폰·PC 사이에 모두 오갑니다.
> 반복 규칙도 같은 태그(`rrule=`, `exdates=`)로 오가므로 **재배포 없이** 요일 다중 선택·종료일·횟수가 맞아집니다.
>
> **v1.2.0부터는 `Code.gs`를 새로 붙여넣고 다시 배포해야 육아 데이터가 시트로 오갑니다.**

### 육아 데이터와 아이 이름

- 육아 일정(아이·종류·날짜·시간·장소·준비물·메모·반복 RRULE·제외날짜)은 `육아일정` 탭에,
  아이 이름·색상은 `육아프로필` 탭에 저장됩니다.
- **기본 이름은 `아이 1`·`아이 2`** 이고, **⚙ 설정 → 육아 — 아이** 에서 바꾸면 시트에 저장되어 휴대폰·PC에도 같은 이름으로 보입니다.
  (공개 저장소 코드·문서에는 실제 이름이 들어 있지 않습니다.)
- 육아 데이터만 따로 **JSON 내보내기/가져오기**할 수 있습니다(설정 → 육아).

> **이미 쓰고 있던 시트라면** `Code.gs`를 새 버전으로 다시 붙여넣고
> **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** 하세요(백엔드 1.0.1부터).
> 캘린더 탭에 `수정시각` 열이 생기고, 캘린더 이름·색상·표시여부도 일정처럼 기기끼리 오갑니다.
> 예전 백엔드 그대로면 캘린더 이름은 이 기기에만 저장되고 시트로는 올라가지 않습니다.
구글 캘린더 전송을 처음 쓰면 캘린더 권한 승인 창이 한 번 뜹니다.

## 되는 것

- **보기 전환**: 상단 **월 · 주 · 일 · 일정** 탭(휴대폰은 바 아래 줄), 단축키 `1/D` 일간 · `2/W` 주간 · `3/M` 월간 · `4/A` 일정 · `T` 오늘
- **날짜 숫자 클릭**: 월간의 날짜 숫자, 주간의 요일·날짜 머리 → 그 날 **일간 보기** (일간 화면의 날짜 머리는 주간으로)
- **월간**: 일정 막대(종일=색 채움, 시간 일정=점+시간), 날짜 칸 클릭 → 그 자리 빠른 등록,
  일정 클릭 → 상세 팝오버(수정·삭제·완료·구글 전송), **끌어서 다른 날짜로 이동**, 2025~2028 한국 공휴일과 대체공휴일
- **주간 / 일간**: 00:00~24:00 시간 그리드, 현재 시각 빨간 선, 빈 시간 클릭 → 빠른 등록,
  빈 시간 **끌어서 시간 범위 지정**, 겹치는 일정 나란히 배치
- **일정**: 날짜순 목록(오늘부터 1년), 반복·구글 전송 배지
- **일정 편집**: 제목, 종일, 시작/종료(날짜·시간), 반복, 캘린더, **일정 하나만의 색**(흑색 포함), **완료**, 장소, 설명
- **반복(개인 캘린더·육아 동일)**: `반복 안함` · `매일` · `매주` · `평일(월~금)` · `2주마다` · `매월` · `매년` · `맞춤 반복`
  — **요일 다중 선택**(예: 월·화·목), **간격**(2주/3개월마다…), **종료 조건**(계속 / 종료일 지정 / 횟수 지정).
  표준 RRULE(`FREQ=WEEKLY;INTERVAL=2;BYDAY=MO,TU,TH;UNTIL=20261231`)로 저장되어 화면·시트·휴대폰이 모두 같게 펼칩니다.
- **반복 일정 수정·삭제 범위**: 반복 회차를 고칠 때 **이 일정만**(그 날만 빼고 단독 일정으로) /
  **이 일정 및 향후 일정**(그 전날까지로 자르고 새 시리즈) / **모든 일정**(시리즈 전체) 중에서 고릅니다.
  '이 일정만'은 `exdates`(건너뛴 회차)로 기억되어 두 기기에 함께 반영됩니다.
- **완료 체크**: 상세의 `✓ 완료` → 그 일정만 흑색 + ✓ + 취소선. 다시 누르면 원래 색으로 돌아옵니다.
  월간·주간·일간·일정 목록·검색 모두에 반영되고, 구글 캘린더로 보낼 때는 색 ID `8`(그래파이트)로 갑니다.
- **캘린더 관리**: 추가·이름/색 변경·숨김, 숨긴 캘린더의 일정은 화면에서 사라짐
- **검색**: 제목·장소·설명에서 찾아 해당 날짜로 이동
- **설정**: 시트 연결/해제, 시트에서 새로 고침, 링크 복사(`#s=<base64>`), JSON 내보내기/가져오기, 전체 삭제, 주 시작(일/월)
- **연결 칩**: 왼쪽 아래에 마지막 동기화 시각·상태 표시, 누르면 즉시 동기화
- **모바일**: 서랍형 사이드바, 하단 + 버튼, 반응형 월/주/일/일정 화면
- 단축키: `T` 오늘, `M` 월간, `W` 주간, `D` 일간, `A` 일정, `N` 새 일정, `←/→` 이동, `/` 검색, `Esc` 닫기

## 1차 시제품의 한계 (의도적으로 뺌) — v1.1.0 기준

- **알림(푸시) 없음** — 웹앱이라 백그라운드 알림이 불안정합니다. 알림이 필요한 일정만 구글 캘린더로 보내세요.
- **반복 예외** — “이번 주만 시간 변경” 대신 ‘이 일정만/이 일정 및 향후/모든 일정’ 범위를 골라 처리합니다
  (반복 규칙 자체를 새로 짜는 ‘반복 맞춤 설정’은 지원하지 않습니다).
- **구글 전송은 첫 회차만** — Apps Script `CalendarApp` 이 반복 규칙을 만들지 못해,
  반복 일정을 보내면 첫 회차 하루만 복사되고 설명에 “반복 일정”이라는 안내가 붙습니다.
- **구글 전송 대상은 기본 캘린더 하나** — 캘린더를 골라 보내지는 않습니다.
- **실시간 아님** — 같은 순간에 양쪽 화면이 함께 바뀌지는 않습니다. 화면으로 돌아올 때·1분마다 맞춥니다.
- 시간 입력은 브라우저 기본 날짜/시간 선택기를 씁니다(브라우저 언어에 따라 표기 형식이 다름).

## 개인정보

- 앱에는 실제 개인정보가 없습니다. 데모 일정은 전부 가상입니다.
- 일정은 연결한 비공개 시트(또는 이 브라우저) 밖으로 나가지 않습니다.
- 웹 앱 주소(`.../exec`)를 아는 사람은 시트의 일정을 읽고 쓸 수 있으니 주소는 공개하지 마세요.
- 공개 저장소에 올릴 때도 시트 ID·웹 앱 주소는 코드에 넣지 않고 `#s=` 링크나 브라우저에만 둡니다.
