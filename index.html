설정

Firebase 실시간 동기화 꺼짐
Firebase 콘솔의 프로젝트 설정 → 내 앱 → SDK 설정 및 구성 → 구성 값을 그대로 붙여넣으세요("const firebaseConfig = { … };" 통째로도 됨). 저장하면 PC에서 고친 일정이 0.3초 안에 휴대폰 화면에 새로고침 없이 나타나고, Google 로그인한 본인 계정만 읽고 쓸 수 있습니다.
비공개 구글 시트 연결 로컬
Firebase를 쓰는 동안에는 이 시트 동기화를 쉼니다(설정은 그대로 남아 있고, Firebase를 끄면 다시 씁니다).
Apps Script 웹 앱 주소(.../exec)를 넣으면 일정이 내 비공개 시트에 저장되고, 휴대폰·다른 PC에서도 같은 일정을 봅니다.
육아 — 아이
이름을 바꾸면 이 기기와 비공개 시트에 함께 저장되어 휴대폰·PC에도 같은 이름으로 보입니다. 공개 저장소에는 기본값(아이 1·아이 2)만 들어 있습니다.
