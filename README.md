# 내 캘린더 — 구글 캘린더 스타일 개인 캘린더 (1차 시제품)

공용 PC(네이버 웨일)에서도 구글 계정 전환·재로그인 없이 개인 일정을 따로 관리하고,
꼭 남길 일정만 `📤 구글 캘린더로 보내기`로 내 구글 캘린더(기본)에 복사해 아카이빙하는 웹 캘린더입니다.
**파일 하나(`index.html`)** 로 동작하고, 일정은 이 브라우저(localStorage) 또는 **비공개 구글 시트**에만 저장됩니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체(HTML+CSS+JS 한 파일). 더블클릭으로 바로 열립니다. |
| `apps-script/Code.gs` | 비공개 구글 시트 백엔드 + 구글 캘린더 전송 API (Google Apps Script) |
| `test/verify.py` | Playwright 자동 검증 스크립트(데스크톱 1440×900 / 모바일 390×844) |

## 바로 열어 보기

- **PC**: `index.html` 을 웨일에 끌어다 놓거나 더블클릭합니다.
- **휴대폰**: 파일을 열거나, 나중에 GitHub Pages에 올리면 링크로 엽니다.
- **데모 데이터**: 주소 끝에 `?demo=1` 을 붙이면 가상의 일정(운동·가족 외식·투자 복기 등)이 채워집니다.
  (`index.html?demo=1`) 실제 개인정보는 들어 있지 않습니다.
- 앱만으로도 일정 추가·수정·삭제, 캘린더 색 구분, 검색이 모두 이 브라우저에 저장되며 동작합니다.
- 처음 열면 빈 달력에 **「가상 일정으로 둘러보기」** 안내가 떠서, 버튼 한 번으로 데모 일정을 채워 볼 수 있습니다.

## 비공개 구글 시트 연결 (휴대폰·다른 PC와 같은 일정 보기)

1. 새 스프레드시트를 만들고 이름을 `[비공개] 내 캘린더` 로 정합니다.
2. 메뉴 **확장 프로그램 → Apps Script** → 기본 코드를 지우고 `apps-script/Code.gs` 내용을 그대로 붙여넣고 저장.
3. **배포 → 새 배포 → 유형(⚙) = 웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **모든 사용자** (그래야 페이지에서 부를 수 있습니다)
   - 배포 → 권한 승인 → 웹 앱 URL(`.../exec`) 복사
4. 캘린더 오른쪽 위 **⚙ 설정**에 URL을 붙여넣고 **[연결]**.
   - 처음 한 번 “Google hasn't verified this app” 경고가 나오면 **고급 → (안전하지 않음)으로 이동 → 허용**.
5. 이미 이 브라우저에 일정이 있다면 설정의 **[이 브라우저 일정 시트로 올리기]** 를 한 번 누릅니다.

시트 탭(`일정`·`캘린더`·`설정`)은 처음 호출할 때 자동으로 만들어집니다.
구글 캘린더 전송을 처음 쓰면 캘린더 권한 승인 창이 한 번 뜹니다.

## 되는 것

- **월간**: 일정 막대(종일=색 채움, 시간 일정=점+시간), 날짜 칸 클릭 → 그 자리 빠른 등록,
  일정 클릭 → 상세 팝오버(수정·삭제·구글 전송), **끌어서 다른 날짜로 이동**, 2025~2028 한국 공휴일과 대체공휴일
- **주간 / 일간**: 00:00~24:00 시간 그리드, 현재 시각 빨간 선, 빈 시간 클릭 → 빠른 등록,
  빈 시간 **끌어서 시간 범위 지정**, 겹치는 일정 나란히 배치
- **일정**: 날짜순 목록(오늘부터 1년), 반복·구글 전송 배지
- **일정 편집**: 제목, 종일, 시작/종료(날짜·시간), 반복(매주·매월·매년), 캘린더 색, 장소, 설명
- **캘린더 관리**: 추가·이름/색 변경·숨김, 숨긴 캘린더의 일정은 화면에서 사라짐
- **검색**: 제목·장소·설명에서 찾아 해당 날짜로 이동
- **설정**: 시트 연결/해제, 링크 복사(`#s=<base64>`), JSON 내보내기/가져오기, 전체 삭제, 주 시작(일/월)
- **모바일**: 서랍형 사이드바, 하단 + 버튼, 반응형 월/주/일/일정 화면
- 단축키: `T` 오늘, `M` 월간, `W` 주간, `D` 일간, `A` 일정, `N` 새 일정, `←/→` 이동, `/` 검색, `Esc` 닫기

## 1차 시제품의 한계 (의도적으로 뺀 것)

- **알림(푸시) 없음** — 웹앱이라 백그라운드 알림이 불안정합니다. 알림이 필요한 일정만 구글 캘린더로 보내세요.
- **반복 예외 없음** — “이번 주만 시간 변경” 같은 예외는 지원하지 않고, 반복은 시리즈 전체에 적용됩니다.
- **구글 전송은 첫 회차만** — Apps Script `CalendarApp` 이 반복 규칙을 만들지 못해,
  반복 일정을 보내면 첫 회차 하루만 복사되고 설명에 “반복 일정”이라는 안내가 붙습니다.
- **구글 전송 대상은 기본 캘린더 하나** — 캘린더를 골라 보내지는 않습니다.
- **여러 기기 동시 편집** — 마지막에 저장한 쪽이 이깁니다(충돌 병합 없음).
- 시간 입력은 브라우저 기본 날짜/시간 선택기를 씁니다(브라우저 언어에 따라 표기 형식이 다름).

## 개인정보

- 앱에는 실제 개인정보가 없습니다. 데모 일정은 전부 가상입니다.
- 일정은 연결한 비공개 시트(또는 이 브라우저) 밖으로 나가지 않습니다.
- 웹 앱 주소(`.../exec`)를 아는 사람은 시트의 일정을 읽고 쓸 수 있으니 주소는 공개하지 마세요.
- 공개 저장소에 올릴 때도 시트 ID·웹 앱 주소는 코드에 넣지 않고 `#s=` 링크나 브라우저에만 둡니다.
